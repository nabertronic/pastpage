# Support

PastPage is maintained by Alexander Nabert.

## Contact

- Email: `nabert@pm.me`
- Project repository: <https://github.com/nabertronic/pastpage>
- Issue tracker: <https://github.com/nabertronic/pastpage/issues>

## What To Include In A Support Request

- browser and version
- extension version
- page URL you tried to recover
- which action you used: popup, context menu, recovery bar, or direct provider action
- what happened instead of the expected result
